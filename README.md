Crop Yield Failure Risk Scoring Using Probabilistic Decision Trees

An integrated two-stage statistical machine learning framework implemented in Python and R.

Stage 1 (Python): Data preprocessing, Bayesian Probabilistic Decision Tree training using Beta-Binomial conjugate updating, and prediction output generation.
Stage 2 (R): Statistical hypothesis testing (paired t-test), evaluation metrics, and publication visualizations using ggplot2 and pROC.

Execution:
python stage1_model.py
Rscript stage2_analysis.R
